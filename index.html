How it works

LIMITS WE’RE DESIGNING AROUND

ONE DOWNLOAD

Models are fetched once, so students set up before they travel.

A CAPABLE LAPTOP

Local AI uses a lot of memory. We’re testing on 16 GB and can drop to a smaller model.

MESSY HANDWRITING

Text recognition can misread notes, so students can check the text before a quiz.

AI CAN BE WRONG

It can write a bad question, so every question links back to its source.
